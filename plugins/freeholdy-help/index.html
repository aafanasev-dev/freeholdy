freeholdy

A single-VPS orchestrator that puts your Docker apps behind nginx + Let's Encrypt, each live at its own *.your_domain.com subdomain — with HTTPS wired up automatically.

📁 Folder deploy

Push a local project folder. freeholdy auto-detects your Dockerfile or docker-compose.yml, builds it, runs it, and wires up nginx + SSL — no config to write.

🔗 Git deploy

Deploy straight from a git URL — public repos, or private ones via the server's own SSH key. Re-clone any time to redeploy the latest commit.

🧩 Plugins

One-command installs of pre-packaged apps — Nextcloud, a full mailserver, Jitsi Meet, a VPN server, and more — provisioned and served in minutes.

⏮️ Versions & rollback

Every deploy is blue/green with archived backups: a failed build never takes the live site down, and you can roll back to any previous version instantly.
